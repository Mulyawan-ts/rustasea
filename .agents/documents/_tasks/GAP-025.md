# [GAP-025] Internal Generator Count Contradiction

### 1. Context & Analysis

- **Trigger**: 
The number of `make:*` generators is stated three different ways across the documentation, and at least one of the stated numbers is wrong. Because the generator count is used as a headline metric for milestone M5, the contradiction erodes trust in the whole milestone status table.

- **Observation**: 
`README.md:170` lists the M5 `make:*` scope and ends the list with the phrase "15 kinds". `docs/milestones.md:48` presents a summary matrix that claims "16 `make:*` generators". `docs/milestones.md:247` lists the generators by name and enumerates 17: controller, middleware, request, model, provider, command, job, event, listener, observer, test, seeder, migration, agent, tool, action, module. The implementation agrees with the 17-count: `crates/rustasea-cli/src/generators/mod.rs:19-54` defines exactly 17 variants of `pub enum Kind`: Controller, Middleware, Request, Model, Provider, Command, Job, Event, Listener, Observer, Test, Seeder, Migration, Agent, Tool, Action, Module. `Kind::parse` at `:58-79` maps each name string to a variant, and the `kinds/` directory holds 18 files (17 kind modules plus `mod.rs`). The requirements document is also short: `.agents/documents/requirements/prd.md:143` (FR-501) lists only 12 generators (controller, model, provider, command, job, event, listener, observer, test, seeder, agent, tool), omitting middleware, request, migration, action, and module.

- **Goal**: 
Reconcile the generator count to exactly 17 everywhere it is stated, across `README.md`, `docs/milestones.md`, and `.agents/documents/requirements/prd.md`, so each document lists the same 17 names and the same total.

### 2. Step & Implementation

1. Fix `README.md:170`: replace the "15 kinds" phrasing with the full 17-name list or a 17-count that matches the enum.
2. Fix `docs/milestones.md:48`: change "16 `make:*` generators" to 17, consistent with the named list already present at `docs/milestones.md:247`.
3. Fix `.agents/documents/requirements/prd.md:143` (FR-501): extend the generator list to all 17 names, adding middleware, request, migration, action, and module to the existing 12.
4. Cross-reference the canonical source: note in each document that the authoritative list is `crates/rustasea-cli/src/generators/mod.rs:19-54` (`enum Kind`).
5. Confirm no other document states a competing generator count.

### 3. Acceptance & Verification

- **Checklist**: 
  - [ ] `README.md` states 17 generators and matches the enum.
