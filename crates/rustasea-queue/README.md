# rustasea-queue

Typed Job trait, central Queue::route registry, sync/database/redis drivers, chain/batch, and Cloud queue metrics.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-queue = "0.1"
```
