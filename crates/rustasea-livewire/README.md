# rustasea-livewire

RustaSea Livewire analogue: askama components, HTMX partial swaps, and rustasea-broadcast realtime updates.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-livewire = "0.1"
```
