# rustasea-debugbar

Dev-only request profiler / debug toolbar (ADOPT-009): SQL, cache, and event capture per request with an in-memory ring buffer and JSON/HTML surface.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-debugbar = "0.1"
```
