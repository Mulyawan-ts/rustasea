# rustasea-app

RustaSea runnable app scaffold. `cargo dev` serves the example HTTP application.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

This crate is the runnable example application, not a published library. It is marked `publish = false` and is meant to be run from a checkout, not depended on.

## Usage

```toml
[dependencies]
rustasea-app = "0.1"
```
