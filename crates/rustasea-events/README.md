# rustasea-events

Event/Listener traits, immediate and after-response dispatch, and async listeners via Queue{enable:true}.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-events = "0.1"
```
