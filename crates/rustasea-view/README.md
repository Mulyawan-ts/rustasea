# rustasea-view

RustaSea view layer: ViewEngine with askama (default) and minijinja (runtime-templates).

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-view = "0.1"
```
