# rustasea-logging

RustaSea logging: Laravel-style logging.toml channels mapped onto tracing.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-logging = "0.1"
```
