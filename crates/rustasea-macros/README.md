# rustasea-macros

Procedural macros for RustaSea: route, middleware, authorize, tries, backoff, timeout, usage, help, and hidden.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-macros = "0.1"
```
