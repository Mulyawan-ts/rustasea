# rustasea-auth

RustaSea authentication and security: JWT/session guards, origin-aware CSRF, and throttling.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-auth = "0.1"
```
