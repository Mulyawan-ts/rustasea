# rustasea-inertia

RustaSea Inertia server: Page<T> envelope, X-Inertia header contract, partial reloads, and shared props.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-inertia = "0.1"
```
