# rustasea-cli

RustaSea Artisan-like CLI: clap + xtask, list, make:* generators, prompts, Artisan::call, and Shutdownable.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-cli = "0.1"
```
