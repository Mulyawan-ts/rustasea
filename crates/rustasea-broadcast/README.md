# rustasea-broadcast

RustaSea broadcast: ShouldBroadcast channels, WebSocket auth, and SSE eventStream.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-broadcast = "0.1"
```
