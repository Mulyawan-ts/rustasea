# rustasea-search

RustaSea search: vector search trait, whereVectorSimilarTo, toEmbeddings, and dropVectorIndex.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-search = "0.1"
```
