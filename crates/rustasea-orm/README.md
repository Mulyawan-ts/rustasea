# rustasea-orm

RustaSea ORM: models, fluent query builder, migrations, factories, and vector support.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-orm = "0.1"
```
