# rustasea-cache

Store/Repository cache traits with memory (moka-like) and redis (feature-gated) stores, TTL touch, and distributed Lock.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-cache = "0.1"
```
