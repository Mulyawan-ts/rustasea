# rustasea-excel

Excel/CSV import-export (ADOPT-023): streaming import with row validation, chunked/queued export to storage, and signed download links (maatwebsite/excel parity).

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-excel = "0.1"
```
