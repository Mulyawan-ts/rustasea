# rustasea-schedule

Scheduler with daily/cron/everyMinute frequencies, pause/resume, skipIfStillRunning, onOneServer, and schedule events.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-schedule = "0.1"
```
