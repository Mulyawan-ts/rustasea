# rustasea-inertia-adapters

RustaSea Inertia WASM presentation adapters: Dioxus (react), Leptos (vue), and Sycamore (svelte) variants.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-inertia-adapters = "0.1"
```
