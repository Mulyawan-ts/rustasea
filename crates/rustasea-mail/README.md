# rustasea-mail

RustaSea mail: Mailable/Mailer contracts, transports, and queued notifications.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-mail = "0.1"
```
