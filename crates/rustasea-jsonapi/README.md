# rustasea-jsonapi

RustaSea JSON:API: JsonApiResource, sparse fieldsets, inclusion, links, and vnd.api+json.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-jsonapi = "0.1"
```
