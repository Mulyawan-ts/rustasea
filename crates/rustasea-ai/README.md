# rustasea-ai

RustaSea AI SDK: provider-agnostic AiProvider trait, Agent/Tool, MCP, and deferred loaders.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-ai = "0.1"
```
