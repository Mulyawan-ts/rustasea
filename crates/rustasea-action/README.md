# rustasea-action

Action pattern (ADOPT-028): one unit of work invoked across HTTP, queue, CLI, and events with validate/authorize hooks (laravel-actions parity).

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-action = "0.1"
```
