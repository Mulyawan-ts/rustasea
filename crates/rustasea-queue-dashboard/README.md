# rustasea-queue-dashboard

Queue dashboard (ADOPT-021): metrics history, failed-job management, and a background metrics sampler (laravel/horizon parity).

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-queue-dashboard = "0.1"
```
