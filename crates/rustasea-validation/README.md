# rustasea-validation

RustaSea validation: strict rules, ErrorBag, and FormRequest.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-validation = "0.1"
```
