# rustasea-testing

RustaSea testing harness: TestCase, testcontainers isolation, factory sequence resets, and paginator views.

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-testing = "0.1"
```
