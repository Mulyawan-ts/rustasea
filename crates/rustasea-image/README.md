# rustasea-image

Image manipulation (ADOPT-024): fluent transform pipeline, EXIF auto-orient, storage round-trip, and queued transforms (intervention/image parity).

Part of the [RustaSea framework](https://github.com/rustasea/framework) - a Laravel-inspired developer experience for Rust.

## Usage

```toml
[dependencies]
rustasea-image = "0.1"
```
